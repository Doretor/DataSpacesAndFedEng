TASK 4: SPATIAL FILTERING (LOCATION)

1. What is a Bounding Box (bbox)?
A Bounding Box is a virtual rectangle drawn on a map to limit our search area. 
Instead of downloading data for the whole world, we tell the server to only give us pictures that fall inside this specific rectangle.

2. How is it defined?
It is defined by four coordinates: [Minimum Longitude, Minimum Latitude, Maximum Longitude, Maximum Latitude]. 
For example, the bottom-left corner and the top-right corner of the rectangle.

3. Example Query (Gdansk, Poland):
We used the bounding box: [18.4, 54.3, 19.0, 54.8].
This effectively filtered the massive Copernicus database to only return satellite images that intersect with the Baltic Sea coast near Gdansk.

4. Why is spatial filtering so important in Earth Observation?
Satellites generate millions of gigabytes of data every single day. 
If we try to search without a location filter, the servers would crash, and we would be overwhelmed with useless data. 
Spatial filtering allows us to instantly find exactly what we need, saving internet bandwidth, time, and computer power.

5. Does the picture perfectly match the box?
Usually, no. Satellites take pictures in large, fixed squares. If our tiny bounding box touches even a small corner of a massive satellite tile, 
the server will return the entire tile. We can later crop the image ourselves if we only need a specific city.
